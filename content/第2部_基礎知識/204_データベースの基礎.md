# データベースの基礎

多くのシステムで使用されるデータベースの基礎知識を学びます。

## データベースとは

データベースとは、データを効率的に保存・管理・検索するためのシステムです。

ほとんどのビジネスアプリケーションはデータベースを使用しています。

## リレーショナルデータベース

最も広く使われているのがリレーショナルデータベース（RDB）です。

### テーブル

データは「テーブル」という表形式で保存されます。

**例：ユーザーテーブル**

| id | name | email | created_at |
|----|------|-------|------------|
| 1 | 田中太郎 | tanaka@example.com | 2024-01-01 |
| 2 | 山田花子 | yamada@example.com | 2024-01-02 |

- **行（レコード）**：1件のデータ
- **列（カラム）**：データの項目

### キー

| 種類 | 説明 |
|------|------|
| 主キー（Primary Key） | 各レコードを一意に識別する列。例：id |
| 外部キー（Foreign Key） | 他のテーブルとの関連を示す列 |

## SQLの基礎

SQL（Structured Query Language）は、データベースを操作するための言語です。

### SELECT（データの取得）

```sql
-- 全件取得
SELECT * FROM users;

-- 特定の列を取得
SELECT name, email FROM users;

-- 条件を指定
SELECT * FROM users WHERE id = 1;

-- 並び替え
SELECT * FROM users ORDER BY created_at DESC;

-- 件数制限
SELECT * FROM users LIMIT 10;
```

### INSERT（データの追加）

```sql
INSERT INTO users (name, email, created_at)
VALUES ('鈴木一郎', 'suzuki@example.com', '2024-01-03');
```

### UPDATE（データの更新）

```sql
UPDATE users
SET email = 'new_email@example.com'
WHERE id = 1;
```

### DELETE（データの削除）

```sql
DELETE FROM users WHERE id = 1;
```

### JOIN（テーブルの結合）

複数のテーブルを結合してデータを取得します。

```sql
-- usersテーブルとordersテーブルを結合
SELECT users.name, orders.total
FROM users
JOIN orders ON users.id = orders.user_id;
```

## よく使うSQL

### 件数を数える

```sql
SELECT COUNT(*) FROM users;
```

### 重複を除く

```sql
SELECT DISTINCT category FROM products;
```

### 条件を複数指定

```sql
-- AND（両方満たす）
SELECT * FROM users WHERE age >= 20 AND age < 30;

-- OR（いずれかを満たす）
SELECT * FROM users WHERE status = 'active' OR status = 'pending';
```

### 部分一致検索

```sql
-- 「田」を含む名前
SELECT * FROM users WHERE name LIKE '%田%';
```

### NULL の扱い

```sql
-- NULLのレコードを取得
SELECT * FROM users WHERE email IS NULL;

-- NULLでないレコードを取得
SELECT * FROM users WHERE email IS NOT NULL;
```

## トランザクション

トランザクションとは、複数の操作をひとまとまりとして扱う仕組みです。

### なぜ必要か

例：銀行の振込処理
1. Aさんの口座から1万円を引く
2. Bさんの口座に1万円を足す

もし1の後にエラーが起きたら、Aさんのお金だけ消えてしまいます。
トランザクションを使えば、両方成功するか、両方失敗するかのどちらかになります。

### 基本的な使い方

```sql
BEGIN;  -- トランザクション開始

UPDATE accounts SET balance = balance - 10000 WHERE id = 1;
UPDATE accounts SET balance = balance + 10000 WHERE id = 2;

COMMIT;  -- 確定（両方の変更を反映）
-- または
ROLLBACK;  -- 取り消し（変更を元に戻す）
```

## 1年目で覚えておくこと

### 必須

- SELECT（データの取得）の基本
- WHERE句での条件指定
- INSERT、UPDATE、DELETEの基本

### できれば

- JOINの基本
- トランザクションの概念

### 詳細は必要になってから

- インデックス
- パフォーマンスチューニング
- 複雑なクエリ

## 注意事項

### 本番データベースの操作は慎重に

- 本番環境でのUPDATE、DELETEは特に注意
- 必ずWHERE句を付ける
- 実行前に確認する

### よくあるミス

```sql
-- 危険！全レコードが削除される
DELETE FROM users;

-- 正しい（条件を指定）
DELETE FROM users WHERE id = 1;
```

## まとめ

- データベースはデータを効率的に管理するシステム
- SQLでデータの取得・追加・更新・削除を行う
- まずはSELECT文をしっかり覚える
- 本番データの操作は慎重に
