# 開発環境の基礎

エンジニアが使う開発環境の基本的な構成要素を理解しましょう。

## 開発環境とは

開発環境とは、プログラムを作成・実行・テストするために必要なソフトウェアや設定の集合です。

## 主要な構成要素

### 1. IDE（統合開発環境）

プログラムを書くための専用ソフトウェア。

| IDE | 主な用途 |
|-----|---------|
| Visual Studio | C#、.NET開発 |
| Visual Studio Code | 多言語対応の軽量エディタ |
| IntelliJ IDEA | Java開発 |
| Eclipse | Java開発 |
| Xcode | iOS/macOS開発 |
| Android Studio | Android開発 |

**IDEの主な機能**
- コード補完（入力候補の表示）
- シンタックスハイライト（色分け表示）
- デバッグ機能
- バージョン管理との連携

### 2. バージョン管理システム

コードの変更履歴を管理するシステム。

**Git**が最も広く使われています。

**基本的な概念**

| 用語 | 意味 |
|------|------|
| リポジトリ | コードを保存する場所 |
| コミット | 変更を記録すること |
| プッシュ | ローカルの変更をリモートに送ること |
| プル | リモートの変更をローカルに取り込むこと |
| ブランチ | 作業を分岐させること |
| マージ | 分岐した作業を統合すること |

**基本的なコマンド**
```bash
git status      # 状態を確認
git add .       # 変更をステージング
git commit -m "メッセージ"  # コミット
git push        # プッシュ
git pull        # プル
```

### 3. ビルドツール

ソースコードを実行可能な形式に変換するツール。

| ツール | 言語 |
|--------|------|
| MSBuild | C#/.NET |
| Maven/Gradle | Java |
| npm/yarn | JavaScript |
| make | C/C++ |

**ビルドとは**
- ソースコードをコンパイル（機械語に変換）
- 必要なファイルを集めてパッケージング
- 実行可能な状態にする

### 4. 開発サーバー・実行環境

開発中にプログラムを動かす環境。

- **ローカル環境**：自分のPCで動かす
- **開発環境**：チームで共有する開発用サーバー
- **ステージング環境**：本番に近い確認用環境
- **本番環境**：実際にユーザーが使う環境

## 環境構築の基本

### 1. 必要なソフトウェアをインストール

- IDE
- 言語のランタイム（Java、Node.js、Pythonなど）
- データベース（必要に応じて）
- Gitクライアント

### 2. プロジェクトの取得

```bash
git clone [リポジトリURL]
```

### 3. 依存関係のインストール

```bash
# Node.jsの場合
npm install

# Javaの場合
mvn install
```

### 4. 設定ファイルの確認

- 環境変数
- 接続先の設定
- 認証情報

## よくあるトラブルと対処法

### 「動かない」とき

1. エラーメッセージを確認する
2. 必要なソフトウェアがインストールされているか確認
3. バージョンが合っているか確認
4. 設定ファイルが正しいか確認

### 環境構築で困ったら

- プロジェクトのREADMEを読む
- 先輩に聞く
- 環境構築手順書を確認する

## まとめ

- **IDE**：コードを書くためのツール
- **Git**：コードの変更履歴を管理
- **ビルドツール**：実行可能な形式に変換
- 環境構築は手順書に従い、困ったら相談する
