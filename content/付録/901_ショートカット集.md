# ショートカット集

よく使うショートカットキーをまとめました。覚えると作業効率が大幅に上がります。

> **Macユーザーの方へ**：基本的に `Ctrl` → `Cmd`、`Alt` → `Option` に読み替えてください。Mac固有のショートカットは各セクションで補足しています。

---

## Git（コマンドライン）

よく使うコマンドのエイリアス設定例：

```bash
# .gitconfig に設定
[alias]
    st = status
    co = checkout
    br = branch
    ci = commit
    df = diff
    lg = log --oneline --graph
    unstage = reset HEAD --
    last = log -1 HEAD
```

## 覚え方のコツ

### 1. まず基本操作を覚える

- Ctrl + C/V/Z は必須
- F12（定義へ移動）は超頻出
- Ctrl + P（ファイル検索）は毎日使う

### 2. 毎日使うものから覚える

- 使用頻度の高いものから
- 1週間に2〜3個ずつ
- 無理に全部覚えようとしない

### 3. マウスを使いそうになったら止まる

- 「これショートカットあるかな？」と考える
- 調べて覚える
- 3回マウスで操作したらショートカットを調べる

### 4. チートシートを活用する

- デスクに貼っておく
- 見ながら使う
- IDE内のショートカット一覧（Ctrl + K, Ctrl + S など）も活用

### 5. IDEのショートカット設定を確認

各IDEには「キーマップ」設定があります。よく使うショートカットが使いにくい位置にあれば、カスタマイズすることもできます。
